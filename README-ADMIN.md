# Bull Bike — сайт + админ-панель

Здесь описано, как всё устроено и как запустить.

## Что сделано

1. **Домен** — везде исправлено `bull-bike.ru` → `bullbike.ru`.
2. **Яндекс.Метрика** (ID `111769809`) вставлена в `<head>` всех страниц
   (`index.html`, `certificate.html`, `privacy.html`, `terms.html`).
3. **Новая админка** в папке `admin/` — вход по логину/паролю, тёмный
   дизайн в стиле сайта, редактирование всего контента, загрузка фото с живым
   превью и смещением кадра (перетаскиванием/ползунками).
4. **Бэкенд** в папке `backend/` — функция для Yandex Cloud, которая проверяет
   логин/пароль и сохраняет изменения прямо в репозиторий GitHub.
5. **Старое удалено**: конфиг Decap CMS от проекта МотоГОСТ (`admin/config.yml`)
   и Cloudflare-функции (`functions/`), которые на GitHub Pages не работают.

## Как работает

```
Админка (bullbike.ru/admin)
   │  вход логин/пароль, сохранение
   ▼
Yandex Cloud Function (хранит токен GitHub)
   │  commit в content/*.json и images/*
   ▼
GitHub репозиторий  →  GitHub Pages пересобирает сайт (1–2 мин)
```

Сайт — статичный. Весь редактируемый контент лежит в `content/*.json`, а `assets/site-cms.js`
подставляет его на страницы при загрузке (включая позицию фото — то самое
«смещение фото»).

## Запуск — 3 шага

### Шаг 1. Сайт на GitHub Pages

1. Залей содержимое архива в свой GitHub-репозиторий.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Домен `bullbike.ru` уже прописан в файле `CNAME`.

### Шаг 2. Бэкенд на Yandex Cloud

См. подробную инструкцию в **`backend/README.md`**. Кратко:
- создать GitHub-токен (Contents: Read and write);
- создать публичную Cloud Function (nodejs18), entrypoint `index.handler`;
- задать переменные: `ADMIN_LOGIN`, `ADMIN_PASSWORD_HASH`, `JWT_SECRET`,
  `GITHUB_TOKEN`, `GITHUB_REPO`, `GITHUB_BRANCH`, `ALLOW_ORIGIN`.

### Шаг 3. Связать админку с бэкендом

В файле `admin/assets/config.js` вставь URL функции в `API_BASE`, закоммить.

Готово: админка — `https://bullbike.ru/admin/`.

## Что можно редактировать в админке

- **Главный экран** — текст, кнопки, фото (десктоп + мобильное) с смещением кадра.
- **Как проходит** — карточки форматов, фото и шаги.
- **Услуги** — карточки техники + содержимое окна «Подробнее» (вступление, пункты, фото).
- **Галерея** — добавление/удаление и порядок фото.
- **О нас**, **Что входит**, **Контакты**, **Сезон/акция**.

При загрузке нового фото оно показывается в рамке блока; перетаскиванием или
ползунками выбирается, какая часть видна. После «Сохранить» точно такая же позиция
применяется на сайте (hero, О нас, Фото услуг и фото форматов).
